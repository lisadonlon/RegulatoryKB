## Findings Detail

### F-01 · `emailer.py` hardcoded fallback — `*@vertigenius.com` (P2 — CARRY-OVER)

**Status:** Unfixed since first reported 2026-06-07.

**Pattern:** `config.get("intelligence.email.sender", "*@vertigenius.com")` — a real company-domain address used as a code-level default. No secret/credential; only domain exposure. If config is absent the fallback fires, potentially sending email from an unintended address.

**Recommendation:** Replace fallback with an empty string `""` or `"noreply@example.com"`. Raise a `ValueError` if sender is unconfigured rather than silently falling back to a hardcoded address.

### F-02 · `config/config.yaml` configured addresses — `*@donlonlsc.com` (LOW)

**Recommendation:** Consider replacing committed config values with `${SMTP_SENDER}` / `${DIGEST_RECIPIENT}` environment variable references and documenting via `.env.example` instead.
