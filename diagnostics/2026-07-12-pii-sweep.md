### Finding Detail

**Finding H-1** (`45d151f6` — `.env.example`):
Pattern `sk-ant-your-key-here...` matched the Anthropic key shape. Confirmed placeholder — the string itself is not a valid credential. No action needed; `.env.example` is the correct place for this.

**Findings H-2 & H-3** (`70408302`, `ab54d3ab` — `scripts/regkb/web/main.py:35`):
```python
secret_key = os.environ.get("REGKB_SECRET_KEY", "regkb-secret-change-in-production")
```
The fallback string `"regkb-secret-change-in-production"` is not a secret — it is public in the repo. Any deployment that omits `REGKB_SECRET_KEY` will use this known string as the session signing key, reducing session security to zero. The env-var pattern is correct; the unsafe default should be removed.

**Recommended fix:**
```python
secret_key = os.environ.get("REGKB_SECRET_KEY")
if not secret_key:
    raise RuntimeError("REGKB_SECRET_KEY environment variable must be set")
```
